Proyecto grupal desarrollado durante la universidad. Lideré el desarrollo
de la API REST y toda la lógica de backend, aplicando el patrón de diseño
Factoría y principios SOLID. Construí la base de datos relacional con
PostgreSQL, usando Docker para la ejecución en local, e implementé CI/CD
para mejorar la fiabilidad de las entregas. También integré AWS S3 para
el almacenamiento de las imágenes de las cartas.
